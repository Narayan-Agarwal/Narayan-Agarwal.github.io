01

metamind

esports analytics platform — 158 csvs pipelined into a postgresql warehouse, explored through a four-page streamlit dashboard.

the problem — competitive valorant stats exist only as hundreds of raw kaggle csvs; there is no clean way to query, rank or compare players across seasons.

what i built — an etl pipeline (normalize → clean → dedup → validate → batch upsert) feeding a nine-table normalised postgresql schema with two materialized views for percentile and consistency scoring using sql window functions; a four-page streamlit dashboard with plotly radar, scatter and gauge charts plus query-level caching; 24 unit tests running in github actions ci.

02

odisha-aqi-advisor

next-day air-quality prediction for ten odisha cities across the industrial corridor, built with xgboost and shipped as a live app.

the problem — odisha's industrial-corridor cities consistently record its highest aqi, but the underlying station data is sparse, messy and hard to turn into a usable forecast.

what i built — a four-notebook pipeline (cleaning → feature engineering → eda → modelling) with lag and seasonal features (monsoon, diwali, industrial peak); an xgboost regressor benchmarked against a linear baseline, with saved per-city models; the readme keeps an honest known-limitations section (no weather data, training window 2019–2023).

  • python
  • xgboost
  • jupyter
  • streamlit

03

skillscope

job-market intelligence — what skills real postings demand, ninety-one companies to explore, and a resume that scores itself against a job description.

the problem — students can't see which skills the market actually asks for, or which ones their own resume is missing for a specific role.

what i built — a skill-demand dashboard and role × skill heatmap from kaggle + adzuna job data; an explorer for 91 companies across 6 tiers; a resume gap analyzer that parses a pdf resume, compares it to a job description and returns a match score with prioritised gap skills, backed by a 250+-entry skill taxonomy, sqlite storage and pytest + hypothesis tests.

04

bgp-security-rpki-validator

route-origin validation for bgp — detect a cryptographically invalid route in python, then reject it on real frr routers.

the problem — bgp runs on trust: any unauthorised system can announce someone else's prefix and redirect traffic. rpki adds cryptographic proof of who may originate a route.

what i built — a two-part hybrid: a tkinter gui detection core that checks a route's origin as against an rpki cache and marks it valid/invalid, and an enforcement core on linux vms running frrouting, configured to reject the invalid route. the demo hijacks the well-known 8.8.8.0/24 prefix from unauthorised as 65535 — the system flags it invalid and the router drops it (show ip bgp returns "network not in table").

  • python
  • tkinter
  • frrouting
  • linux
